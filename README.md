Uber Data Analysis Dashboard
​A comprehensive Power BI data analytics project designed to evaluate operational performance, booking metrics, and revenue trends across different vehicle categories like Bike, Auto, and Premier Sedans. This dashboard serves as a key decision-making tool for tracking fleet efficiency, understanding user behavior, and monitoring regional financial performance.
​Key Insights & Features
​1. Unified Dashboard Navigation
​The report features a dynamic multi-tab architecture for a granular deep dive into distinct performance pillars:
​Home / Overview: High-level executive summary of performance metrics.
​Vehicle Analysis: Granular performance breakdowns categorized by distinct transit types (e.g., Bike, Auto, Mini, Prime Sedan, Uber XL).
​Revenue Performance: Deeper look into cash flows, billing frequencies, and top clients.
​Rider Cohorts: Segmenting riders into First-Time Users, Regulars, and Loyalists.
​Location Analytics: Tracking regional request concentrations and pickup hot spots.
​2. Core Metrics Tracked (KPIs)
​Total Revenue: High-level tracking of active cash flows (e.g., 11M for specific vehicle categories).
​Ride Status Breakdown: Clear visual segmentations showing Completed trips vs. Incomplete (operational issues) vs. Cancelled (user or driver actions) statuses.
​Fleet Efficiency Metrics: Monitoring variables like Total Distance Traveled, Average Trip Distance, and Lost Rides to track service optimization.
​Customer Lifetime Value (CLV): Segmented lists displaying revenue contributed by individual Customer IDs to easily isolate high-value patrons.
​3. Deep-Dive Analytical Views
​Revenue by Payment Method: Visual distribution across transaction channels (Cash, Credit Card, Mobile Wallets) to understand consumer preferences.
​Temporal Trend Analysis: Interactive line and area charts tracking ride frequencies and revenue generation scaled over monthly and quarterly trends.
​Rider Segmentation Logic: Dynamic tracking of demographic buckets indicating whether user cohorts are growing or stabilizing over time.
​Tech Stack & Tools Used
​Business Intelligence / Visualization: Power BI Desktop
​Data Sources: Structured tabular datasets mapping Uber transactional records
​Core Concepts Applied: Data Modeling, DAX (Data Analysis Expressions) for custom KPIs, Interactive Filter Panes, and Cohort Analysis.
